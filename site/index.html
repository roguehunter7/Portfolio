The Story

Six phases, from a hand-built VM to a zero-ingress password vault. Each phase has its own architecture and its own reason — read the full archive.

  1. 1 · Bootstrap & GitOps polling Historical
    Hand-deployed VM, then a pull-based GitOps loop; moved to push-based deploys and hardened it.
  2. 2 · Observability & IaC serverless Historical
    Live metrics daemon, LaTeX resume in CI, then a full Terraform + Cloud Run / Firestore serverless rebuild.
  3. 3 · Zero-ingress Docker Compose Historical
    Serverless costs returned the stack to a hardened VM — no public ports, everything through a Cloudflare Tunnel.
  4. 4 · Edge migration to Cloudflare Pages Historical
    Static site moved to the edge; hardened headers, robots/llms.txt, JSON-LD, CI-rendered resume PDF.
  5. 5 · Repurposing the compute Historical
    The freed VMs became a Hermes AI host, then a zero-ingress Oracle dev box with a browser terminal.
  6. 6 · Vaultwarden host (current) Live
    The GCP e2-micro now serves a self-hosted password vault — loopback-only, least-privilege IAM, nightly GCS backup.
