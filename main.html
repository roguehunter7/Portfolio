I don't just "deploy code"—I build bulletproof environments. This site is a live demonstration of how I migrated a resource-constrained GCP micro-node from a clever "hack" to a hardened, enterprise-standard CI/CD pipeline.

PHASE 1: THE MVP

Native Resource Polling

Problem: Running GitHub Actions runners or Jenkins on a 1GB RAM GCP e2-micro instance is a suicide mission for the Linux OOM-killer.

Decision: I built a "Runner-less" GitOps loop using a systemd.timer and a Bash script. It polled the GitHub API every 2 minutes for SHA changes.

Result: 0MB extra RAM used, but 2-minute latency and high API overhead.

PHASE 2: MODERNIZED

Push-Based IAP Tunneling

Problem: Pull-based polling is inefficient and security was "root-heavy." I needed an enterprise-grade pipeline without opening public ports.

Decision: Replaced the poller with GitHub Actions. Used GCP Identity-Aware Proxy (IAP) to tunnel deployments via Port 22 while keeping the public firewall closed.

Result: Instant deployments, zero open public ports, and unprivileged Docker runtimes.

Why I Built It This Way

  • Stealth Origin: I hate open ports. By using Cloudflare Tunnels for traffic and IAP for deployments, my server doesn't exist on the public internet. If you scan my IP, you get nothing.
  • Unprivileged Runtimes: Most people run Docker as root. I switched to the nginx-unprivileged image to ensure that even if the container is breached, the attacker is stuck in a sandbox with no system permissions.
  • Infrastructure as Code: Every firewall rule, VPC subnet, and compute node is in my main.tf. I can destroy this entire project and bring it back to life in 45 seconds with 100% parity.
